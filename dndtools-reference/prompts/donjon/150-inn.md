# Inn Generator

Read `00-shared.md` first. Implement only this tool.

## Catalog

- key: `inn-generator`
- label: Inn Generator
- href: `/tools/inn-generator`
- description: Generate an inn or tavern with a keeper, a menu, patrons, and rumors.
- source: `Site tables`

## Goal

One inn, in sections that reroll independently: name, location, description, keeper, menu, patrons, rumors. Quality and crowd change the prices and the patron list.

## Input

```ts
type InnInput = {
  quality: "poor" | "common" | "good";
  patrons: "townsfolk" | "adventurers";
};
```

## Sections

Write original tables in `src/lib/inn/tables.ts`.

- Name: 40 patterns. Inn or tavern. Clicking the name rerolls it. If `src/lib/names` has an inn catalog, use it for half of the rolls and the local patterns for the rest.
- Location: 12 sentences (lane, bridge, market, roadside, docks).
- Description: 16 sentences. Poor inns mention worn furniture or cheap tallow. Good inns mention private rooms or a named wine. Common sits between them.
- Keeper: 20 sentences that include `named {Name}`.
- Menu: 6 dishes. Each dish is a name plus a price in cp or sp. Poor prices are 1-4 cp. Common are 5-20 cp. Good are 2-8 sp. Drinks: 3 items with the same price bands. Use the seeded rng, not a fresh random call.
- Patrons: 4 short people. Townsfolk are trades (cooper, clerk, fisher). Adventurers are class and race words a 3.5 DM expects (fighter, cleric, rogue, wizard, ranger, human, dwarf, elf, halfling, half-orc). One sentence each, including what they are doing.
- Rumors: 3 rumors. Each is one sentence and may be false. Mark one of the three, at random, with the label "Unreliable". Do not explain which is true.

Reroll salts: name 1, location 2, description 3, keeper 4, menu 5, patrons 6, rumors 7. Changing quality or patrons rerolls every section.

## UI

Same section pattern as Magic Shop: title button, then each block with a Reroll button. Menu is a table with Dish and Price. Patrons and rumors are lists.

Class prefix: `.inn-gen`.

## Tests

- Poor menu prices are at most 4 cp. Treat sp as 10 cp in the assertion helper.
- Good menu includes at least one price in sp.
- Adventurer patrons mention one of the class words. Townsfolk patrons do not mention "wizard".
- Exactly one rumor is marked unreliable.
- Rerolling the menu does not change the keeper for the same base seed.

## Acceptance

- Page on `/tools` with all six sections.
- Tests and typecheck pass.
